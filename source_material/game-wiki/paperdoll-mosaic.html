Engine-rendered paperdoll mosaic

Implemented bounded presentation, November 2. In I → Sprites, Godot draws an opaque coarse mosaic over the reference body's groin on front/back, beneath actual clothing. It samples/quantizes the base image into blocks at runtime, using authored normalized regions and reference-canvas block size. The PNG has no baked mosaic. See the runtime guide, full-body fixture, appearance, inventory, presentation and ledger. No SCP canon changes.

Committed outfit, visual overlay

Actual worn garment alpha conceals the overlay; real underwear/trousers removal reveals it after paid commitment. Held/stored gear does not conceal it. It has no item identity, mass, fit, physical access mask, storage or protection and adds no time/AP bypass. Picking continues through actual garment alpha and never selects the mosaic. Both sides use the same resized letterbox transform. Body inspection and normal inventory services retain physical authority.

The renderer draws base → engine mosaic → worn layers → foreground head. Tile generation is separate readable presentation code. Matching saved outfits reconstruct the mosaic without a flag or content-identity change; the original slice was qualified on schema 14.

Every depicted pocket is usable

Current contract, November 5, 2026: if item artwork depicts a pocket or pouch, it must have usable storage. This supersedes the decorative-pocket limitations in earlier pocket slices. It is an equipment authoring rule, not an SCP canon claim or automatic image inference.

Every worn-side target still requires actual visible opaque pixels. Covered pockets remain inaccessible through ordinary physical coverage services.

Authoring and interaction

A depicted pocket needs an ordinary region definition, physical dimensions/load limits, correct front/back access footprint, independent fastening/default state and visual segment/hotspot linking to that region. Add a new compartment only for genuinely separate storage. Multiple illustrations or mounting sides must reuse the existing item/region identity. Review the gear standard, asset library, mapped coverage, worn drops and shirt/badge boundary.

Hover and inspection do not grant storage access. Opening, moving, arranging and securing retain normal time/AP, pause refusal, source retention and commit-time validation. Grid drops remain exact; deliberate container drops use scoped packing. Opening one pocket never opens its siblings. Moving the owning item carries all contents once. Painted badge pixels never grant credentials.

The kit remains 20 definitions/40 instances; immutable content identity changes because new region definitions and initial states were added. Start a fresh scene. Matching saves remain schema 15; old mismatched kits reject atomically. No new mutable save field or image segmentation service is introduced. The enlarged coat illustration uses closed reference art even when its front is physically open; state labels and commands remain authoritative. World wardrobe art, general body variants, fastening animation and final capacity balance remain future work.

Verification

Domain checks cover complete region sets, closed refusal, independent paid storage, rear surfaces and exact loaded continuation. Native checks exercise all four worn coat contours, both coat states and rear trouser/cargo input. Backpack checks include all three compartments on both mounts. Run python3 tools/run_spatial_scene.py --check, --pocket-smoke PNG or full --inventory-smoke PNG. Actual results belong in the runtime review; a wiki build does not run gameplay checks.

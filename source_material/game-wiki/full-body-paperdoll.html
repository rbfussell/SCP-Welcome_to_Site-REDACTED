Full-body paperdoll and base garments

Implemented bounded fixture, November 2. I → Sprites now shows one front/back reference body with real underwear, socks, trousers, shirt, work shoes, an open/closed coat and a field backpack. This follows the original upper-body proof. See the runtime/data guide, appearance contract, inventory, presentation and implementation ledger. No SCP canon or anomalous rule is changed.

One physical outfit, multiple visual parts

The appearance adapter selects actual own compatible worn mounts/default poses and committed fastening state. Stored, held, foreign and packed items are excluded. Manifest version 2 registers several PNGs, front/back source rectangles and destination parts on one canvas. A pair of socks or shoes has two independently positioned draw parts, with one physical item/parent/mass.

The normal waist belt/direct pouch extends this to eight wearable bindings and the original direct attachment binding; the worn hook-chain follow-up adds the front hook → pouch chain; other strap poses remain unqualified.

Source alpha, layering, optional per-part front/back selection and the same letterbox transform govern drawing, tint and picking. The backpack harness is drawn behind its mounted-side bag at the same shoulder scale as the opposite view. Transparent gaps/padding do not acquire cell fills or rectangular targets. The fixture's alpha cutoff stays 0.1; it is not a production material policy. Foreground head/neck or hair keeps collars behind the head. Qualified long sleeves use authored base-body cutouts to prevent stand-in arm/shoulder clipping. These suppress only the reference body, never real gear or physical cover, and are not a general transparent/torn-cloth solver.

The native view selects/inspects/opens normal context actions. Shoe removal reveals socks; sock removal reveals feet after paid completion. Hex fitting, body drops, inspection/removal and mount providers remain separate authorities. Other body pocket segments, arbitrary attachment artwork/strap poses, all body variants and world wardrobe composition remain future work. Unsupported worn gear is explicitly omitted.

Base garment and honest visual fallback

underwear / avatar-underwear is now real cotton boxer briefs: 80 g, 100×100×15 mm packed, no storage, an authored pelvis/upper-thigh fit profile and linked front/back surfaces. It precedes trousers in actual worn order; covered removal refuses normally. The existing handler supplies time/AP, fit/bulk checks, descendant ownership, source retention and mass accounting.

The current base (full-body-v2.png) is shirtless with close-fitting matte tan fabric briefs. Their compact warm-tan silhouette replaces the original painted tank top/loose shorts without changing real equipment. These pixels are visual reference art, not items, protection or containers. Actual navy underwear can be removed while the engine mosaic/reference remains; the sprite cannot imply it is still equipped. The original PNG is preserved. The earlier featureless mannequin request produced no accepted asset; the user-selected clothed alternative is now accepted, with exact edit prompts/hashes linked from the runtime guide.

At this slice’s qualification, native content had 19 definitions, 39 instances, 9 fit profiles; the current shirt/badge kit has 20 definitions and 40 instances, with the same nine fit profiles. Persistence was schema 14 at this slice’s qualification, but immutable content identity changes: older-kit saves need a fresh start. Matching new saves retain exact paid continuation. There is no automatic underwear injection/migration. The native crate is not enlarged; test-only helper-held outer gear provides valid staging for undressing checks without adding a player handoff feature.
